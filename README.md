# Employee-Data-Analysis Using Microsoft Excel
## **PROJECT OVERVIEW**
This project focuses on analysising employee data using Microsoft Excel to explore workfore demographics, identify patterns and generate meaningful insights that support better understanding of employee information. The analysis involves data organisation, data cleaning, the use of Pivot Tables, Excel formulas, and data visualisation to create an interactive dashboard.
## **OBJECTIVES**
-Examine employee demographic information
-analyse workforce distribution and patterns
-identify key trends within the employee dataset
-present findings through an interactive Excel dashboard
## **TOOLS AND SKILLS**
- Microsoft Excel
- Data cleaning
- Pivot tables
- Excel Formulas
- Data analysis
- Data visualisation
- Dashboard Development
## **PROJECT OUTCOME**
An interactive Excel dashboard presenting key employee data insights in a clear and accessible format
## **KEY INSIGHTS AND FINDINGS**
## KEY AREAS OF ANALYSIS
- 1. Gender Distribution by Age group: examines employee gender representation across different age categories
- 2. Gender Distribution by Country: analyses employee gender representation across different countries
- 3. Gender Diastribution by Department: examines the distribution of employees by gender across departments
- 4. Annual Salary by Department and Gender: compares total annual salary across departments, with a breakdown by gender
- 5. Bonus Distribution by Ethnicity and Gender: examines total employee bonuses across different ethnic groups, broken down by gender
## **DASHBOARD VISUALISATION**
The dashboard uses Pivot Tables, pie charts and Column charts to represnet workforce demographics, salary compatisions and bonus distribution in an interactive and understandable format/
